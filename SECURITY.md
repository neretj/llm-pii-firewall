# Security policy

## Supported versions

Security fixes are provided for the latest release line.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** feature. Do not open a
public issue for possible PII disclosure, bypasses, credential exposure or
remote inference vulnerabilities.

If private reporting is unavailable, contact `nereajensen@gmail.com` with the
subject `PII Firewall security report`. Include affected versions,
reproduction steps and impact, but never include real personal data,
production credentials or customer payloads.
